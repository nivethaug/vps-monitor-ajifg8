## 📝 Description

Add a new dedicated **"Performance"** page to the VPS Monitor dashboard. This page will focus on real-time system performance metrics — separate from the general Dashboard — showing CPU, Memory, Disk, and Network trends in depth. It reuses the existing dark theme, card style, chart components, and data-refresh system so it feels native to the app.

The page uses **demo/sample data** for now (matching the other pages). It can later be connected to real VPS agent data. A **1h / 6h / 24h time-range switcher** is included.

---

## 🎯 What the User Will Experience

- A new **"Performance"** entry appears in the left sidebar menu (between "Docker Fleet" and "Dashboard").
- Clicking it opens a page with:
  - **Top row — 4 KPI cards**: CPU %, Memory %, Disk usage %, Network I/O
  - **CPU & Memory trend chart** (line graph, respects time-range)
  - **Network traffic chart** — upload/download speeds over time
  - **Disk I/O chart** — read/write speeds over time
  - **Load average + process count** mini-panel
  - **Time range switcher** — 1 hour / 6 hours / 24 hours
- Same dark theme, icons, card style, and top bar (Refresh + Auto-refresh 30s) as existing pages.
